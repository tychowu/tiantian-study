# 節日時光機：雙語與內容核查

更新：2026-09-22。本次只作本地修改，未發布。

## 介面與互動

- 中文／English 切換涵蓋 16 張卡片、四個關卡、月份、季節、選項、結果提示及節日曆。
- 卡片正文點讀按當前語言使用粵語優先或英語；切換時停止上一段語音。
- 切換保留目前卡片、關卡、作答、配對及已認識的節日，不因切換重開遊戲。
- 「吃／玩什麼」改為「吃什麼」，活動欄不再列出吃食物。
- 移除「郵戳已收集」標記；保留節日曆。
- 月份是示意，不冒充特定年份的日曆。移動節日接受可能的月份，並顯示日期規則。
- 地區配對明確按公眾假期分類，不等同只有該地慶祝；中秋香港翌日放假。

## 逐項檢查

| 節日 | 核查／調整 |
| --- | --- |
| 元旦 | 1 月 1 日；倒數屬跨年前夕，不作元旦必備活動；無固定食品。 |
| 除夕 | 農曆年末；團年飯、魚、雞、年糕；辭舊迎新，闔家團圓。 |
| 春節 | 正月初一；活動與食物分開；恭喜發財，大吉大利。 |
| 元宵 | 正月十五；湯圓、元宵，餃子標明部分地區。 |
| 清明 | 約 4 月 4 或 5 日；廣東燒味例子與各地綠色米食分開，艾粄和青團不是完全相同的食品。 |
| 復活節 | 3 或 4 月的星期日，教會曆法計算，不直接等同天文滿月；雞蛋、巧克力蛋、熱十字麵包。 |
| 勞動節 | 5 月 1 日；感謝工作者；沒有固定食品。 |
| 佛誕 | 香港採農曆四月初八；浴佛與慈悲；部分信眾素食，不強稱所有人如此。 |
| 端午 | 五月初五；龍舟、屈原故事與部分地區掛艾草；食品為粽子。 |
| 香港回歸紀念日 | 7 月 1 日，1997 年成立的是香港特別行政區，不是香港城市誕生；不保證每年有煙花。 |
| 中秋 | 八月十五；家人團聚、賞月、燈籠；月餅、柚子；不聲稱當晚一定是天文上最圓時刻。 |
| 國慶 | 10 月 1 日；升旗與慶祝活動；無固定食品。 |
| 重陽 | 九月初九；登高、賞菊、祭祖；重陽糕標明部分地區。 |
| 萬聖節 | 10 月 31 日；服裝、南瓜燈、討糖；食物不含燈籠。 |
| 冬至 | 約 12 月 21 或 22 日；短日長夜限定香港／北半球；食品註明南北習俗不同。 |
| 聖誕 | 12 月 25 日；裝飾、禮物、歌曲；薑餅、蛋糕、火雞標明地方差異；聖誕老人視為文化故事，不當作事實。 |

祝福語是適合兒童的表達示例，並非每個節日都有唯一固定句式；英文以容易理解的意思表達，不強求逐字翻譯。香港公眾假期與僱傭條例法定假日並非完全相同，這裡不作僱傭法指引。

- 香港海關：[清明應節食品巡查](https://www.info.gov.hk/gia/general/202404/03/P2024040300377.htm) — 本地清明燒味食品。
- 香港佛教聯合會：[2026 分區佛誕活動](https://www.hkbuddhist.org/editor_upload_image/bbd2026-district.pdf) — 浴佛與素食活動例子。
- BBC School Radio：[Spring 2016](https://downloads.bbc.co.uk/schoolradio/pdfs/somethingtothinkabout_spring_2016.pdf) — 復活節兒童活動與熱十字麵包。
- 香港天文台：[24 Solar Terms](https://www.hko.gov.hk/en/gts/time/24solarterms.htm) — 清明、冬至屬節氣。
